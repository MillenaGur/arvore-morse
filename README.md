# arvore-morse

inserir elementos: o código pega a frase de elemento, divide entre eles usando espaço como indicador onde começa e termina uma palavra, salva em um lista.
Depois começa um for para cada palavra dessa lista e  um outro for para cada letra da palavra.
Para inserir ele vê se o valor seja ponto (menor) para esquerda ou traço (maior) para direita, casotenha um lugar dispovivel ou seja null é adicionado ali se não é passado pra proxima folha e continua na proxima letra da palavra até encontrar um valor nulo.
